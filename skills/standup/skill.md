# /standup — Update de Status para Cliente

Gera um update profissional pronto para enviar ao cliente ou equipe.

## O que faz

Analisa o contexto do projeto atual e produz um update estruturado com:
- O que foi feito desde o último update
- O que está em andamento agora
- O que está bloqueado (se houver)
- O que vem a seguir

## Uso

```
/standup
/standup semana     ← visão semanal em vez de diária
/standup cliente    ← versão mais formal, sem jargão técnico
```

## Formato padrão

```
📋 Update — [data]

✅ Concluído
- [item 1]
- [item 2]

🔄 Em andamento
- [item] — previsão: [data/período]

⛔ Bloqueios
- (nenhum) ou descrição do bloqueio

➡️ Próximos passos
1. [próximo passo]
```

## Dica

Use `/standup cliente` antes de enviar para o WhatsApp ou e-mail do cliente — a linguagem é adaptada para não-técnicos.
