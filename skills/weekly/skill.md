# /weekly — Resumo Semanal

Visão consolidada da semana para planejamento e retrospectiva.

## O que faz

Gera um resumo da semana com:
- O que foi entregue (por projeto)
- Tempo estimado por cliente/projeto
- O que ficou para a próxima semana
- Uma métrica de produtividade simples
- Decisão de foco para a próxima semana

## Uso

```
/weekly
/weekly retrospectiva     ← foco no que aprender da semana
/weekly planejamento      ← foco no que priorizar na próxima
```

## Formato

```
## Semana — [período]

### Entregas
| Projeto | O que foi feito | Tempo (est.) |
|---------|-----------------|--------------|
| [proj]  | [item]          | Xh           |

### Carregou para a próxima semana
- [item pendente]

### Aprendizados
- [algo que funcionou]
- [algo que não funcionou]

### Foco da próxima semana
**Prioridade 1:** [item]  
**Prioridade 2:** [item]  
**Descartar/adiar:** [item]
```

## Diferença do /daily

`/daily` → visão do dia, para atualizar cliente  
`/weekly` → visão da semana, para você planejar e aprender
